# Ex-1---Spatial-Descriptions-using-RoboDK.
# Aim
To study and visualize the spatial description of objects and robot coordinate frames using RoboDK software and
understand position, orientation, translation, rotation, and homogeneous transformation in three-dimensional space.
# Apparatus / Software Required
Desktop/Laptop Computer
Windows 10/11
RoboDK Software
Six-axis Industrial Robot (ABB, FANUC, KUKA, UR, etc.) available in RoboDK
Mouse and Keyboard
GitHub link
